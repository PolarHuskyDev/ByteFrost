# ByteFrost
ByteFrost is a compiled programming language with simplicity and safety in mind. It's name is inspired in Norse mythology `Bifröst` often described as a bridge between Midgard and Asgard. Likewise ByteFrost can be seen as bridge between users (developers, Midgard) and the machine (godlike performance, Asgard).

## Compiler architecture
The ByteFrost compiler is a pipeline of multiple layers to provide simplicity, consistency, safety and performance.  

At a high level the compiler looks like:

```mermaid
flowchart TD
    SRC["📄 Source Code (.bf)"]

    subgraph FRONTEND["Frontend"]
        LEX["Lexer\ntext → tokens"]
        PARSE["Parser\ntokens → AST"]
    end

    subgraph SEMANTIC["Semantic Analysis"]
        SYM["Symbol Table\nscopes · visibility · declarations"]
        TRES["Type Resolver\ntype inference · type checking"]
        OWN["Ownership & Nullability\nmutability · null safety"]
        DIAG["Diagnostics\nerrors · warnings"]
        SYM --> TRES --> OWN
        OWN -.->|reports| DIAG
    end

    subgraph MID["Middle-End"]
        HIR["HIR\nHigh-level IR\nfully typed · fully resolved"]
        OPT["Optimizer\nHIR-level passes\nconstant folding · dead code"]
    end

    subgraph BACKEND["Backend"]
        LLVMIR["LLVM IR\nLLVM Lowering"]
        LLVMOPT["LLVM Optimizer\npass pipelines"]
        CG["Code Generation\nobject files"]
    end

    subgraph TARGETS["Target Backends (LLVM target machine)"]
        T_WIN["🪟 Windows\nPE · x86_64-pc-windows-msvc"]
        T_LIN["🐧 Linux\nELF · x86_64-unknown-linux-gnu"]
        T_MAC["🍎 macOS\nMach-O · aarch64-apple-darwin"]
        T_WASM["🌐 WebAssembly\nwasm32-unknown-unknown"]
    end

    SRC --> LEX --> PARSE
    PARSE -->|AST| SEMANTIC
    SEMANTIC -->|SemanticProgram| HIR
    HIR --> OPT
    OPT --> LLVMIR
    LLVMIR --> LLVMOPT --> CG
    CG --> T_WIN
    CG --> T_LIN
    CG --> T_MAC
    CG --> T_WASM
```
